# Sidecar Toy 本地应用使用方法

版本：0.3.1，macOS Apple Silicon（M 系列）预览版。

## 下载与启动

1. 在本项目的 GitHub Releases 找到 **Sidecar Toy Desktop 0.3.1**。
2. 下载 `Sidecar-Toy-0.3.1-mac-arm64.dmg`，打开后将 `Sidecar Toy.app` 拖到“应用程序”；
   也可以下载 `Sidecar-Toy-0.3.1-mac-arm64.zip`，解压获得同一个应用。
3. 双击 `Sidecar Toy.app`。首次启动自动建立本机实验环境，不用终端，不用安装 Python、Node.js 或依赖。

本次仅提供 M 系列 Mac 产物，不是 Intel Mac 或 Windows 安装包。应用包声明最低 macOS 13；
实际验收机器为 Apple Silicon macOS 26.5，不等于所有旧 macOS 都已实机验收。

**签名边界：**应用通过本机 ad-hoc 签名一致性检查，但没有 Apple Developer ID 签名或公证。
从互联网下载后系统可能提示未识别开发者或阻止启动，这不等同于免依赖功能失败。
不要关闭全局 Gatekeeper、不要删除隔离属性来伪装通过公证；只运行自己核验来源和校验和的预览。
需要无警告公开分发时，仍需开发者签名和 Apple 公证。

## 一个人模拟多人协作

应用默认进入 Alice 的任务大厅/采集告知页。顶部 macOS 菜单 **“演示用户”** 可切换：

| 用户 | 快捷键 |
| --- | --- |
| Alice | Command+1 |
| Bob | Command+2 |
| Carol | Command+3 |
| Dave | Command+4 |

每个用户有独立身份、数据库、项目群与同意状态。切换用户会重新载入该用户页面，
未发送的输入不保证跨用户切换保留；先发送或处理完表单再切换。

1. Alice 阅读实验告知，填写昵称、明确同意后进入，点击“发布任务”。
2. 填写标题、任务原文、验收条件并发布。
3. 菜单切换 Bob，独立阅读并确认采集，然后在大厅打开任务、申请接单。
4. 切回 Alice，在申请列表批准 Bob。
5. 切回 Bob，等待“进入项目群”出现，发送消息。
6. Alice 可以指定已入父群的 Bob 负责子任务，Bob 接受后成立独立子群。
7. 子群只能邀请父群现有成员，成员还需确认。最后逐层提交、验收并结束任务。

通讯录、节点双向信任、私聊、项目群与 23 个原生通信 Skill 继续可用。
加入项目群不会自动给所有节点授予长期信任，私聊需要单独建立双向信任。

## 默认离线范围

应用内置一个本地 Relay、任务目录、研究采集服务和四个演示节点，全都仅监听本机回环地址。
启动和演示摘要不需要外网、不需要香橙派、DSH 或 API key。
它不会连接发布者的服务器，不会带入发布者的节点、凭证或数据库。

摘要在界面明确标为 **“演示摘要 · 非模型生成”**。它用于体验任务流程，可能重复任务原文，
不是训练好的模型，也不证明自动理解任务的质量。此应用版不自动下载模型或产生模型调用费用。

“连接设置”保留连接已有 Sidecar 的入口，但它要求服务地址，不是 Relay 地址；
实际多机 HTTPS、证书、访问授权与真实 Harness 仍须单独配置。

## 数据、退出与更新

菜单“文件 → 打开数据目录”可查看实际目录。默认是：

```text
~/Library/Application Support/Sidecar Toy/
```

其中 `workspace/` 保存四个节点身份、任务、群聊及研究数据库，`logs/` 保存诊断日志。
此目录与旧 Sidecar、源码演示、香橙派部署分离，不自动迁移旧数据。

- 关闭最后一个窗口或 Command+Q 会退出应用并停止它启动的全部本地服务。
- 再次打开应用保留身份、采集同意、任务和消息；端口可以变化，无需手工管理。
- 应用只对其本机回环通信绕过代理，不改变系统代理或其他应用的网络设置。
- 更新前退出旧应用，再替换 `.app`；数据在用户目录，不在下载包里。
- 备份须先退出应用，保护整个工作区。备份包含身份私钥和聊天正文，不要发给别人或提交 GitHub。
- 删除应用本身不会自动删除实验数据。

## 采集告知

Toy 用户必须明确同意，才会将本应用私聊、群聊、任务操作和接入 Harness 提供的可见交互收集到
**本地研究数据库**。本地演示默认不会向外部服务器上传。不同演示用户需要分别同意。

只输入合成测试数据，不输入真实隐私、密码或 API key。敏感字段过滤不保证识别所有秘密。
未发送草稿、其他应用聊天和模型隐藏推理不在采集范围。

可以从大厅的用户设置退出采集，停止新增上传；历史研究记录并不会自动删除。
管理员令牌保存在工作区私有文件中，不能分享。开发者需要导出/删除时可使用源码包中的
`research_admin.py`，普通演示并不需要该工具。

## 故障排查

- 启动失败：退出重开；仍失败时查看数据目录的 `logs/backend.log`，分享前先检查敏感内容。
- 任务大厅为空：确认在同一个应用本地工作区，且各用户完成采集告知；刷新页面。
- 批准后尚未入群：等待几秒，后台交换成员清单；不能绕过授权强行加入。
- Mac 架构不符：使用与 CPU 对应的版本；本次 arm64 不用于 Intel Mac。
- 不要把此前源码包当应用安装包，源码 ZIP 和本次 `.app`/DMG 是不同交付物。
