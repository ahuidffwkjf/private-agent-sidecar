# Sidecar Toy 0.3.3：ECS 在线协作

默认模式是每台电脑一个独立 Sidecar 用户，连接 ECS Relay 和同一个任务大厅。
不再使用香橙派；本机 Alice/Bob/Carol/Dave 演示仅在连接设置中主动选择。

## 接入

1. 下载自己系统的安装包，安装后打开 Sidecar Toy，不用安装 Python、Node.js 或 DSH。
2. 首次启动选择默认的「ECS 在线协作」，导入管理员私下提供的接入 JSON 文件。
   核对服务器地址和证书指纹，确认导入后保存并重启。
3. 填写自己的昵称，阅读并明确确认实验采集范围。
4. 从通讯录查看在线节点，可发送联系人申请；双方确认长期信任后才能私聊。
5. 在广播大厅发布任务，然后在任务详情选择「邀请在线用户」，也可在在线联系人的
   资料页选择「邀请参加任务」。对方在新的联系人或任务详情中查看邀请和权限并接受。
6. 入群成功后交流、创建子任务、提交和验收。子群仍只能邀请直接父群成员。

默认部署地址为 `https://189.24.102.37:8787`。ECS 控制台需允许该 TCP 端口入站。
连接失败会显示重试状态，不会自动换成香橙派，也不会自动切成本机四用户演示。
首次导入是授权操作：公开 GitHub 安装包不包含 SSH 密码、Relay 令牌或任何人的身份私钥。
接入文件包含实验接入凭证，请仅通过可信的私密渠道交给获授权参与者，不能放到 GitHub。

## 通信与数据

- 每个用户的私钥、业务数据库和本地研究数据库保存在自己的系统用户数据目录。
- ECS 保存公开任务元数据、注册身份、在线能力广播，并暂存加密的通信信封。
  它不需要聊天正文或群内容密钥；这不是直接连接失败后的隐式回退，而是 ECS 模式明确选择的传输。
- 研究采集仍需本人确认，当前桌面版的研究正文记录保存在本机；本次没有将采集库迁到 ECS。
- 在线以近期签名心跳判断，正常间隔 30 秒、超过 90 秒视为离线；不是永久注册即在线。
- 已排队不等于对方已收到。只有经过对方签名确认才标为已投递；过期或撤销后的消息不会假报成功。
- 默认摘要仍为明确标记的演示摘要，不是实际 DSH 模型输出。
- 卸载和更新不自动删除本机数据。旧本机演示数据与新的 ECS 用户数据分别保存。
- 香橙派旧数据库未删除；因原设备不可达，历史任务尚未迁入 ECS，不能把旧快照当作最新记录。

## 安装包

| 平台 | 文件 |
| --- | --- |
| Windows x64 | `Sidecar-Toy-0.3.3-win-x64.exe` 或完整 ZIP |
| Linux x64 | `Sidecar-Toy-0.3.3-linux-amd64.deb` 或 `Sidecar-Toy-0.3.3-linux-x86_64.AppImage` |
| Mac M 系列 | `Sidecar-Toy-0.3.3-mac-arm64.dmg` 或 ZIP |
| Mac Intel | `Sidecar-Toy-0.3.3-mac-x64.dmg` 或 ZIP |

Windows 尚无商业代码签名，Mac 尚未经过 Apple Developer ID 公证。不要关闭系统安全保护。
Linux 仍需兼容的系统图形库和 sandbox 配置；不使用 `--no-sandbox`。不宣称支持 ARM Linux、
ARM Windows、Android 或 iOS。跨平台原生测试和公网 ECS 验收是两类独立证据。
